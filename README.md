# NLP Comment — анализ тональности отзывов


NLP Comment — мой pet-проект по обработке естественного языка. 

Идея проекта — автоматически определять тональность текстовых отзывов и комментариев: негативную, нейтральную или позитивную.

Для этого я использовал предобученную модель `intfloat/multilingual-e5-base` и дообучил на датасете с отзывами.


## Что можно делать с помощью моего проекта

1. Определять тональность текстовых отзывов и комментариев.
2. Классифицировать текст на три категории: `negative`, `neutral`, `positive`.
3. Получать вероятности принадлежности текста к каждому классу.
.

## Обучение модели

Для проекта я выбрал `intfloat/multilingual-e5-base` — предобученную многоязычную модель для получения векторных представлений текста.

Я использовал её как основу классификатора: к выходу трансформера применил mean pooling, а затем добавил линейный слой для предсказания одного из трёх классов.

Для обучения использовал датасет `ai-forever/ru-reviews-classification` с отзывами, размеченными по тональности.

Датасет разделён на три части:

Обучающая выборка — **45 000 текстов**
Валидационная выборка — **15 000 текстов**
Тестовая выборка — **15 000 текстов**

Модель обучалась с использованием оптимизатора AdamW и функции потерь CrossEntropyLoss.

Параметры обучения:

Количество эпох — 5
Batch size — 8
Learning rate — 2e-5
Weight decay — 0.01
Максимальная длина текста — 256 токенов

Во время обучения я отслеживал loss и метрики на валидационной выборке. Лучшая версия модели сохранялась по значению F1-score (macro).

## Результаты

После обучения я проверил модель на отдельной тестовой выборке из 15 000 отзывов.

Полученные метрики: Accuracy - 0.7787, Precision (macro) - 0.7836, Recall (macro) - 0.7787, F1-score (macro) | 0.7806 |

Модель правильно классифицировала около 77,9% отзывов на тестовой выборке.
